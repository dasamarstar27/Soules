# Soules V25.13

Map in the top toolbar and Explore → World map now open an interactive SVG route map. It shows the main regions and optional realm, current position, defeated guardians and locked destinations. Select a region with a marker or the touch-friendly region picker. The local map and accessible place cards show discovered structures and saved village notes; undiscovered structures stay hidden. Map travel and structure visits use the existing unlock checks, travel menus and structure handlers. Browsing consumes no turns. Leave a fight, village or action submenu before using travel; map reading remains available.

Scrolling resumes for a short response after an explicit new action, including after a previous long passage stopped following. Passive output preserves manually selected history; long passages still stay in place. Initial output is followed after its hidden game panel becomes visible. Command focus uses preventScroll, the toolbar’s actual height determines the embedded desktop layout, and the sidebar retains its manual scroll position. The changes were verified in a resized iframe resembling Replit’s preview; no live Replit instance was available. Pull the latest repository changes and restart Run on Replit to use this release.

Validation: 269 unit tests passed. Browser checks passed for graphical markers, hidden discoveries, locked travel, actual cross-region travel and a village visit, pending-menu safety, mobile overflow, journal length thresholds, action-follow after long output, passive history, an embedded/resized preview, sidebar position, original game menus and version downloads. The original UI regression now expects explicit short-menu actions to resume following; passive-history checks remain in the dedicated journal tests. Simple edition gameplay is unchanged.
