# Soules V25.10

Quarries now award 2 construction Stone plus one regional forging metal. Timber yards award 2 construction Timber plus one regional crafting wood. Each named site remains limited to one trip per 20-wander cycle; existing exhausted sites stay exhausted until their next cycle. Ironpeak’s dwarven quarry now gives Titanium as well as Stone. The expedition mining activity shares the same regional ore table. Existing building menus convert spare wood into Timber and spare metal into Iron fittings.

A separate Soules Simple laptop edition opens directly from a single self-contained HTML file. It keeps the text adventure, sidebar, dictionary, tutorial, 15 original regions and guardians, basic combat, equipment, four permanent rune bindings, forging, village shop/rest, three save slots, export/import, Normal/Easy and colour themes. It starts with only a Rusty Sword. It intentionally omits later seasons and management systems. This is newly written, inspired by an earlier Soules; it is not a recovered V15 archive. Full-game saves and Simple saves are separate.

Extract either ZIP before playing. Full: Play Soules.bat (Python required). Simple: Play Soules Simple.bat, or simple/Play Soules Simple.html (no Python required). Export a Simple save before moving or renaming its HTML file or updating versions; file-based browser storage varies by browser.

Validation: 259 unit tests passed. Browser checks passed for full-game quarry/timber menus and tablet buttons, regional forges, original menus and version downloads. The standalone HTML passed combat, forging costs, permanent rune binding, healing, guardian progression, autosave, manual slots, JSON export/import, foreign-save rejection, death and dictionary checks with network disabled. Managed Chromium blocks direct file:// navigation, so the exact HTML was supplied through an in-memory browser route for that check; Windows double-click launch was not executable in this Linux environment.
