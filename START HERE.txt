PLAY SOULES V25.4

This download lives in a folder named V25.4. Keep the entire folder together.
Close any older Soules server window before starting this version.

1. Extract this whole ZIP into a folder. Do not run it from inside the ZIP.
2. You need Python 3.11 or newer installed from python.org.
   Windows: tick "Add Python to PATH" during installation.
3. Windows: double-click "Play Soules.bat".
   Mac: double-click "Play Soules.command".
   If macOS blocks an unsigned launcher, open this folder in Terminal and run
   python3 play.py instead.
4. The game opens in your browser. Keep the launcher's window open while playing.
   On the first launch, Internet access is needed to install the game's libraries.
5. Choose Play / Continue. Tutorial is on the main menu.

FOR TABLETS WITHOUT A LAPTOP: see "TABLET PLAY.txt". The game must be deployed
to an online host once; Nanu can then play by opening its link, with your laptop
switched off. The ZIP itself is a computer download, not an iPad application.

Use Save slots for multiple characters and Export save for portable backups.
The game stores progress in your browser, so keep the same browser and export a
backup regularly. Saving checkpoints happens at category menus, outside battles. The launcher uses the same local address each time so your save slots remain
available. Keep using the same browser profile; other browsers have separate saves.

All original uploads are preserved in legacy/. The malformed old save cannot be
imported into this browser edition.

HINDI READ-ALOUD FOR NANU

Use Settings / Customise -> Narration language -> Hindi, then press the
"Hindi mein sunein" button (shown in Hindi script) while playing.
A Hindi text-to-speech voice must be installed on that computer or tablet.
Use Hindi setup help in Settings for Windows and iPad instructions.

Supported browsers can translate English to Hindi automatically. If this is not
available, use the browser's Translate page -> Hindi option and select a Hindi
passage to read. The Hindi voice itself does not translate English.
Initial voice/translation downloads or browser translation may need Internet.
No translation account or paid API key is required by Soules.

DIFFICULTY
Choose Normal for the original game balance, or Easy for beginners.
You can also change difficulty in Settings at a village or category menu.
Easy reading and Tablet mode are separate from adventure difficulty.
