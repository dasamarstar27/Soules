SOULES SIMPLE V25.12

Double-click "Play Soules Simple.html" to play in Edge, Chrome, Firefox or Safari.
On Windows you can also double-click "Play Soules Simple.bat" in the parent folder.
No Python, installation, Internet or server needed. Extract the ZIP first.

This is a new simplified edition inspired by an older Soules, not an actual V15
archive. It keeps text gameplay, a character sidebar, dictionary, tutorial,
exploration, 15 regions, combat, guardians, swords, four rune types, basic forging,
a small village shop, Normal/Easy, colour themes, autosave and three save slots.
No later seasons or village-management systems. Full Soules remains separate.

Saves are specific to Simple. Export JSON from Saves before moving/renaming the
HTML, updating versions, or changing computers. Import it in the new copy. Browser
storage for locally opened files depends on the browser, so keep exported backups.

Death clears the active adventure. Manually saved slots remain available.
